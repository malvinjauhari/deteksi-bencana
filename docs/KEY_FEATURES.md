# Key Features

1. **Peta Visual Interaktif:** Render titik koordinat dan radius dampak.
2. **Disaster Feed & Voting:** Daftar *alert* yang diurutkan berdasarkan skor urgensi.
3. **AI Analysis (Bahasa Awam):** Merubah data teknis (Geologi/Meteo) menjadi kalimat mudah dipahami.
4. **Donasi & Transparansi:** Checkout otomatis donasi tanggap darurat yang *campaign*-nya berhasil terbentuk dari *voting* tertinggi.
