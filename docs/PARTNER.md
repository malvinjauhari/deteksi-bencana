# Partner & Validator System

Keputusan akhir (*voting*) dilakukan oleh masyarakat. Setiap validator memiliki bobot berbeda:
- **Pemerintah / Otoritas:** Bobot Tertinggi (mis. 3 poin per vote)
- **NGO / Relawan Terverifikasi (PMI, dll):** Bobot Menengah (mis. 2 poin)
- **Warga Lokal (KTP Terverifikasi):** Bobot Standar (mis. 1 poin)
